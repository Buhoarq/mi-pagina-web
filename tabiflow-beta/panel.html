Configuración

⚖️ Ponderación del avance físico

Peso de cada etapa en el "avance ponderado" y en los m² equivalentes del rendimiento. Deben sumar 100 %. En los tabiques sin plomo, el peso del plomo se suma a la estructura (ej.: metalcon 40 % + 10 % = 50 %). Se publica junto con el avance.

🔑 Token de GitHub (solo coordinación)

Necesario para publicar desde este PC. Crea un token fine-grained en GitHub → Settings → Developer settings → Personal access tokens, con acceso solo al repositorio mi-pagina-web y permiso Contents: Read and write. Se guarda únicamente en este navegador.
